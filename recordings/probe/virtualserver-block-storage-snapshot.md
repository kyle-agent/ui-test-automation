# #/virtualserver/block-storage/detail/info?blockStorageId=… — 볼륨 스냅샷 (2026-09-29 프로브, 에이전트 C)
- 목록에서 볼륨명 셀은 링크가 아니다. 링크는 "볼륨 ID" 셀(둘째 칸).
detail buttons: ["볼륨 이전","스냅샷 복구","스냅샷 생성","Block Storage 삭제"] tabs: 상세 정보 | 스냅샷 목록 (n) | 태그 (n) | 작업 이력
생성 폼(참고): 볼륨명(255자) / 디스크 유형 SSD / 용량 Units(8GB 단위) + GB / AZ kr-west1-b / 스냅샷 "사용"(스냅샷에서 볼륨 생성) / 요금 확인

## "스냅샷 생성" → 모달 "스냅샷 생성"
- 스냅샷명 | input[text] | 영문, 숫자, 공백과 특수문자(-_) 255자 이내
- 설명 | input[text] | 255자
buttons: ["취소","확인(dis)"] → 이름 입력 후 확인 → "스냅샷을 생성하시겠습니까? 스냅샷은 볼륨의 용량 관리에 영향…" → "스냅샷 생성이 성공하였습니다."
- 스냅샷 탭 행: 스냅샷명 | 스냅샷 ID | 설명 | 볼륨 용량 | 생성 일시 | 상태. Creating → Available (수 초 ~ 90초)

## "스냅샷 복구"
- 모달 "스냅샷명: … / 생성 일시 … / 스냅샷을 복구하시겠습니까? / 모든 연결 서버에서 umount 된 상태로…" → 확인
- 볼륨 상태 Reverting(3초 뒤) → 약 70초 뒤 Available. 복구 중 스냅샷 목록에 임시 스냅샷이 하나 더 보였다가(2) 끝나면 사라짐(1)

## 스냅샷 삭제
- 탭 행 선택 → 표 위 "삭제" → "스냅샷명: … / 스냅샷 1개를 삭제하시겠습니까?" → Deleting → 수 초 ~ 90초 뒤 행 사라짐
