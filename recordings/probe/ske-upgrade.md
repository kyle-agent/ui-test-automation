- "업그레이드" 모달 "노드 풀 버전 업그레이드": 서버 OS 드롭다운(Ubuntu 24.04 (Kubernetes)-v1.36.3) → 확인. 목록 "2 / 1 Updating"(서지 노드 1대) → 1 / 1 Running ≈5.5분.

- "레이블 수정" 모달: 추가 → 행(키 · 값 text). "테인트 수정": 추가 → 행(효과 드롭다운 기본 NoSchedule · 키 · 값). 버튼 추가 · 취소 · 확인.
