**결론(2026-10-06)**: 콘솔 SSO 세션은 유휴 30분(keep-alive 로 막음) 외에 **로그인 후 약 12시간 절대 수명**이 있다. 아침에 로그인하면 그날 저녁까지 실행할 수 있고, 야간 무인 실행은 사람 로그인으로는 불가.
keep-alive 는 이제 제목을 최대 20초 기다리고 두 번 연속 실패일 때만 만료로 확정하며, 확정되면 Windows 알림을 띄우고 로그인·마지막 OK 시각을 로그에 남긴다(`src/console/notify.ts`, PW_NOTIFY=0 으로 끔).
